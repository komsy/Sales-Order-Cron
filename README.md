M-Pesa STK Push Cron Service

A Node.js cron-based background service for processing and managing M-Pesa STK Push transactions. This service can be used to automatically initiate STK Push requests, monitor transaction statuses, and sync payment confirmations with your backend system.

Features

Automated cron jobs for scheduled STK Push processing
Initiate M-Pesa STK Push requests
Poll transaction status updates
Handle successful and failed transactions
Retry pending transactions
REST API integration support
Secure token generation and caching
Logging and error handling
SQL/MySQL compatible workflows
